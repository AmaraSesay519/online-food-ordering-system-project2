# Online Food Ordering System

## Project Overview

The **Online Food Ordering System** is a web-based application designed to allow users to browse food menus, register accounts, and simulate food ordering through an interactive web interface. The system demonstrates the core features of an online food ordering platform and provides different dashboards based on user roles.

The project was developed as part of a **Web Programming course project** and focuses on implementing frontend technologies such as **HTML, CSS, and JavaScript**.



## Features

The system includes the following main features:

* User Registration
* Role-Based Login System
* Food Menu Display
* Simulated Food Ordering
* Restaurant Dashboard for Menu Management
* Admin Dashboard for System Management

These features demonstrate how different types of users interact with the platform.



## User Roles

The system supports three main roles:

**1. User (Customer)**

* Browse food menu
* Simulate food ordering

**2. Restaurant**

* Manage food menu
* View customer orders

**3. Admin**

* Manage system users
* Monitor restaurant accounts
* Oversee system activities



## Technologies Used

The project was developed using the following technologies:

* **HTML5** – Structure of the web pages
* **CSS3** – Styling and layout design
* **JavaScript** – Form validation and interactivity



## System Pages

The system includes several web pages:

* Home Page
* Registration Page
* Login Page
* Food Menu Page
* Restaurant Dashboard
* Admin Dashboard

Each page provides specific functionality within the system.
